# 🌸 Sakura & Aurora Clock 樱花极光桌面时钟

一款纯 Win32 GDI 双缓冲打造的梦幻桌面时钟：流光渐变背景、樱花花瓣飘落、指尖生花轨迹、呼吸光点，单文件绿色运行，资源占用极低。

**作者：LXT** ｜ 当前版本 **v1.1**

## ✨ 主要特性

- 🕐 实时走时，24/12 小时制可切换，底部秒进度线
- 🌸 真实樱瓣造型（带缺口 7 点泪滴形）持续飘落，鼠标滑过指尖生花
- 🌈 6 种梦幻色系（极光 / 樱粉 / 幻紫 / 薄荷 / 落日 / 极夜），支持按昼夜自动变色
- 📅 干支生肖年、节日问候、年内第 N 天 / 第 N 周 / 距元旦倒计时
- 🍅 番茄专注计时器（`C` 开关 / `空格` 开始暂停 / `R` 重置），结束自动花瓣雨
- 🖥️ 系统托盘 + 右键菜单、最小化到托盘、单实例运行
- ⌨️ 全局热键：`Ctrl+Alt+A` 设置 / `Ctrl+Alt+W` 桌面控制 / `Ctrl+Alt+T` 置顶 / `Ctrl+Alt+P` 点击穿透
- 🚀 开机自启、边缘吸附、窗口位置记忆、滚轮平滑调节透明度
- 🪟 桌面窗口控制中心：调节任意窗口透明度 / 置顶 / 隐藏窗口、图标、任务栏
- 📐 无边框 8 方向自由缩放，高分屏 Per-Monitor V2 适配，失焦自动降频省电

## ⌨️ 快捷键（时钟窗口内）

| 按键 | 功能 |
|---|---|
| `A` | 个性化设置面板 |
| `W` | 桌面窗口控制中心 |
| `T` | 切换置顶 |
| `C` / `空格` / `R` | 番茄钟开关 / 开始暂停 / 重置 |
| 鼠标滚轮 | 平滑调节透明度 |
| 双击窗口 | 纯净模式 |
| `ESC` | 退出 |
